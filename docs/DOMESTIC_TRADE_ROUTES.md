# 国内の期間別取引件数：正規経路の確認（2026-10-24）

## 2026-10-29：次に解消すべき工程

最新の現行経路で、期間項目未提供が高レア541枚に残る。通常の一括差分で提供開始は検知するが、同じカードの個別取得や店舗在庫再確認で期間件数が埋まるとは扱わない。原票がnullの項目と、項目自体がない状態も分離する。後者の`automatic`表示をfalseへ統一し、通常一括での再確認と不足の自動解消を混同しない。利益計算自体は取引件数を入力としない。厳格な分析可能判定・指定された取引件数条件は別に維持する。

- [Yahoo!公式の終了告知](https://developer.yahoo.co.jp/changelog/2018-02-20-auction160.html)：旧オークションWeb APIは2018-02-22終了。現行の国内成約フィードとして接続しない。
- [メルカリShops公式API](https://api.mercari-shops.com/docs/index.html)：店舗識別トークン・契約時のUser-Agentが必要。自店の注文・取引を一般市場全体の国内PSA10成約へ拡張しない。
- オークファンの既存調査を継承。次に必要なのは「非AIの機械取得、同一日本語仕様/状態/PSAグレード、成約ID/日時と取消、期間網羅性、保存/派生集計公開範囲、料金」の回答。現時点でこの条件を満たす無料の代替フィードは確認できず、未契約のまま実装済み・自動取得中と表示しない。既存文案を利用でき、送信・契約・課金は別承認。

取得できない件数の代わりに出品件数・店舗在庫・重複する30日集計を代用しない。今は国内購入先の追加、鮮度回復、仕様根拠を確定できる保存原票の回収を独立して継続する。

対象は同一日本語カード・仕様・グレードの成約IDと成約日。出品日、更新日、店舗在庫、重複する直近30日集計から期間件数を作らない。今回の新規成約取得・公開は0。

|経路|確認できた範囲|期間・条件・費用|今回の判断|
|---|---|---|---|
|既存みんトレ原票|提供済みの素体全状態/PSA10期間集計。個別成約とは別|現行原票に期間項目がないカードは通常の一括差分で提供開始を検知|未提供579枚を同じページの反復取得で解消可能としない|

|接続済みメルカリ検索/商品詳細ツール|出品/売却済み状態、商品ID、価格、出品/更新からの経過時間|ツールの公開スキーマに成約日時・全市場の網羅件数はない|売却済み検索結果を7/30/75/200日の成約件数へ換算しない。新しい契約・認証は実施せず|

確認根拠：

- [メルカリShops公式API仕様](https://api.mercari-shops.com/docs/index.html)（認証、User-Agent、orderTransactions）。旧ordersは非推奨。利用者の自店取引を公共の市場全体へ拡張しない。
- [オークファン公式提供案内・2026-10-09](https://aucfan.co.jp/press/release/2026/7857/)（対象期間の検索例、契約、初期費用）。個別カード/グレードの収録範囲と自動再利用条件の保証ではない。

不足を解消する新経路には、国内対象、成約日、取引ID、言語/番号/仕様/PSAグレード、取得範囲の完全性、重複範囲、非AIの定期取得と保存/公開権限が必要。料金や契約の承認前に購入・登録・問い合わせ送信を行わない。国内PSA9/状態A個別成約も別の未確立項目として維持する。
