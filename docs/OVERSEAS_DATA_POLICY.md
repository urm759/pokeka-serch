# 海外価格の取得・公開方針

最終確認: 2026-10-19。仕入れ式・GO・固定A/B条件は変更しない。

## PokeDATA公式API優先

- [公式API資料](https://documenter.getpostman.com/view/16115980/2sA3JF9iWW)は有料API・非商用向けと明示し、他用途は問い合わせを案内している。[公式プラン](https://www.pokedata.io/pro)はPersonal API Accessを案内。[利用規約](https://www.iubenda.com/terms-and-conditions/81884871)にもコンテンツの利用・再公開条件がある。
- 収益化しないという意図だけで、仕入れ分析・内部業務・公開JSON・公開リポジトリの許可を確定しない。用途の適用範囲、契約/API権限、保存・公開条件は確認待ち。有料契約・クレジット消費・問い合わせ送信は承認前に行わない。
- 文書化された `/v0/search`、`/v0/sets`、`/v0/set`、`/v0/pricing` を優先する。従来のwebsite用 `/api`、Chromeからの成約収集は停止。公式価格APIの素体区分とPSA10区分は利用可能な仕様だが、個別成約ID・成約日時・期間件数・履歴の提供は確認できていない。
- pricingの通貨付き値は「提供元集計価格」。実成約、推定、出品の内訳が不明なら断定しない。eBay Rawは状態混在・美品未証明。低グレードやPokedata Rawを、確認済み素体実成約の代用にしない。
- API取得日時と提供元の価格確認日時・最終成約日は別。未提供はnull。円換算は通貨・為替基準日が確認できる場合のみ。APIクライアントの模擬試験は実取得や契約確認の成果ではない。

## 内部保存と公開の境界

- 新たなAPI原票は `.private/overseas/api/` にのみ保存。APIキーは環境変数、原票・ログ・JSONへ保存しない。権限確認、日次クレジット上限、同時実行排他、アクセス間隔、タイムアウト、原因別の停止/上限付き再試行を適用する。
- `.private/` はGit追跡・公開・Actionsの退避アップロード対象外。既存原票は内容hashごとにローカル退避し、hashを照合してから公開側を価格なしのメタデータへ置き換える。画面だけで隠す方法にはしない。
- 再生成/コミット前に共通の公開ガードを実行し、別名JSONに混入した海外価格も検知する。解析不明・不一致は公開停止。公開許諾と内部利用許諾は独立し、内部取得が可能になっても自動再公開しない。
- 既に公開されたGitの過去コミットは通常の修正コミットでは消えない。今回は履歴改変・強制pushを行わない。履歴からの除去やキャッシュ削除は影響・復旧方法を説明して別途承認を得る。現行公開の整理を、過去公開分の完全回収とは呼ばない。

## PSA POPと取得率は別管理

- PSA公式の価格新規取得開発は停止。既存の価格原票は内部退避し、現在相場や素体価格に使わない。
- 公式POP・10率・同仕様の実測履歴・チェックポイントは削除しない。取得許諾待ちは既存の `psa-access-policy.json` に従う。ログイン成功だけでは再開しない。
- 取得停止後は個別確認日時に基づき古値になる。公式率・想定率、推定・実測、過去値保持・最新取得成功を混同せず、既存の鮮度/安全判定を維持する。POPの比較履歴が残っていても、最新性が回復したとは扱わない。
