## 食い違いと確認待ち

- `data/publication-lineage.json` の `sources` は公開を作るときに固定するリポジトリ内の入力を列挙する。カードラッシュ・遊々亭は名前が残るが、稼働の根拠は停止方針と実行状態にある。みんトレ出品数、GemRate、取引件数の詳細は個別の原票・要約やUI manifestも確認する。
- 「スニダン」名のPSA10相場・出品項目は、みんトレ提供の集約経路と、停止したスニダン直接経路がある。集約は個別成約明細の代わりにならない。みんトレが集約値を作る元の行や更新条件の全容は、保存済みのデータからは確認できない。
- 名称照合で使う過去のスニダン英語名と、計算で参照し得るPSA公式の過去POPは、入力として現役だが新規取得停止中。ゲートを通らない価格・在庫は集計と計算から外れる。停止中でも保存済み資料が残る。
- 保存済みの取引件数履歴はみんトレの7日・30日集計。個別のPSA10最終成約額を定期表示できる原票は確認できなかった。例としてあったかピカチュウは、最新の期間原票が null／未提供の行と、カード一覧に保存された繰越件数に差がある。
- 取得を続けているのに参照先がないと確定できた元データは、この確認範囲ではなし。古い `data/psa-official-populations.js` など同じ主題の別形式や、旧海外経路の出力は、受け取り処理・保全・過去検証の用途を含めて調べる必要がある。ファイル名の有無だけでは判断しない。
