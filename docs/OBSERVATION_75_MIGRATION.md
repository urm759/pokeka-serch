# 観測比較の75日移行（2026-10-18）

- 独自の価格観測・買取価格観測・個別成約比較は7/30/75/200暦日。同日観測は1回、欠測は補わず、日時付き原票から再集計する。原票は365日以上の既存保持を維持。
- 旧URLの `obs90Min/Max` と保存済み `observation90Min/Max` は同じ数値の75日条件へ移行する。新75日キーがある場合はそちらを優先する。空欄・off・0・逆転した上下限は勝手に補正しない。
- `effScenario=obs90` は `obs75` へ移行する。読み取った元URL／保存条件は端末の `:observation-90-to-75-v1` に退避し、設定欄に説明を表示する。ほかの費用・売却先・承認済み保存条件は保持する。
- 旧要約の90日用コンパクト配列を75日として読まない。要約の `periods` に75がない場合は未取得。価格・資金効率・取引数・CSVは再生成された75日を参照する。
- 75日平均は75日後の予測ではない。資金効率は観測平均のPSA10と現在の国内PSA9を組み合わせた参考試算。買取・両出口では同条件の買取履歴が必要で、フリマ平均への自動切替はしない。
- 鑑定返却日数、91日予測、取得元独自の90日取引・買取掲載・海外期間統計は変更しない。75日で確認できない取引総数はnullのまま。
- 従来90日比較の最低観測数45日を75日比較でも維持する。完全な75日平均・期間別資金効率の非参考扱いは75/75日かつ取得根拠が必要。参考平均の採用設定とGO基準は変更しない。
- ロールバックはGitの旧集計コードと原票から再生成する。旧設定は端末退避、旧公開要約はGit履歴に残る。ラベル変更や75/90倍での変換はしない。
