# GemRate POP 日次受領（導入前）

初期状態は停止。確認済みの日本語・PSAセットだけを通常公開ページで確認し、元基準日が進んだ場合だけ通常の Export to CSV を1回押す。既存セットの日次枠と、確認済み新セットの1日1枠を分ける。CSVの反復処理は新観測にしない。

## 実行範囲と権限

- PCとChromeの起動中だけ動く。PC電源OFF時の新CSV取得を解決するものではない。クラウドの既存受領・公開処理は別。
- GemRate公開ページと、このサイトの公開設定を読むホスト権限、alarms / storage / scripting / downloads を使用する。
- Chromeのdownloads権限自体はダウンロード履歴全体を参照できる。コードが引き取るのは、自分が開始した確認済みセットのCSV（URL・referrer・開始時刻・ジョブID一致）だけ。
- APIキー・契約・課金・新規アカウント・認証回避は使わない。403等のアクセス画面や仕様矛盾は保留し、自動解除しない。
- 安全制限を緩めない。出力開始後に受領不明となった場合は再クリックしない。ダウンロード保存先を確認できなければ保留。

## 保存と受領

専用の Downloads/GemRate-Auto/pending/ジョブID に CSV と receipt.json を保存する。ページの元基準日と確認日時を別記録する。同日未更新の確認では証跡だけを出し、CSVを再取得しない。

既存の毎時PC受領処理が、原本・ハッシュ・バックアップ・仕様を検証し、既存の照合・履歴・最小公開チェックポイントへ接続する。原本と圧縮バックアップの一致を確認した専用フォルダ内の重複コピーだけを整理し、一般のDownloadsや失敗ファイルには触れない。

## 検証状態

単体・実CSV再照合と、拡張導入後の実取得・複数周期の日次運転は別。パッケージ作成時点では未導入・未実運転。導入には利用者による拡張と権限追加の確認が必要。

popup の単発試験は同じ基準日でも一度CSVを出して受領経路を確認するが、新基準日・新POP観測には数えない。保留解除機能は設けない。
