# みんトレ掲載出品数の日次保存

## 今回の実施

- 既存のみんトレ通常一括取得（公開ページ・公開データの3通信）に、PSA10と美品の掲載出品数保存を接続。スニダン直接取得は追加しない。
- 11月4日13:32:57 UTCの実応答でPSA10 5,138枚、美品3,881枚を初回保存。各1観測日。30日は直近30暦日中の実観測日平均であり、現状は1日分の参考値。
- スターミーV CSRはPSA10 10件・美品4件、ピカチュウex M2a234は121件・30件で提供元画面と一致。美品144件が残っていても現在価格なしのミミッキュは美品として不採用。件数だけの旧値へ新日時を付けない。
- 美品は「傷なし」の現在出品価格の根拠も必要。PSA10・素体・傷あり・取引件数・POPを混ぜない。件数は提供元掲載値で、個別出品IDやカード数量を独自検証した件数とは区別する。
- 確認日時は実応答受領時刻。提供元のカード別更新日時は未提供としてnullを保存。成約日・ファイル時刻で代用しない。99以上等の文字列は下限として保持する。121件の実表示は確認したが、上流サービス全体の上限制約まで確認したとは扱わない。
- 新規8条件は初期OFF。現在数・30日平均の上下限を両区分で指定でき、URL・保存・CSVを共通化。出品数を需要・利益・GOへ追加採用しない。
- 月別観測を別保存し、小さい現在要約のみ表示後に1回取得。原票と要約のカタログハッシュを検証し、版混在なら公開を停止。正常データの失敗回収にも月別履歴を含めた。

## 店舗更新と実成果

- 全既知URLは高価格・在庫切れでも対象。最安が在庫切れなら、新鮮な同一仕様の適合在庫から次の店舗へ切り替わる既存処理を回帰確認。
- 通常巡回が30日となっていた設定と既定値を48時間へ修正。重点6時間、通常25%枠、通信間隔・時間枠、採用期限、停止方針は維持。処理枠増加や能力達成の証明ではないため、修正後の複数定期周期は継続確認が必要。
- 通常更新で新掲載4枚、必須不足解消36枚40項目、新規分析可能4枚。国内参考価格がなくなった5枚が不足化し、構造的分析可能は2,505→2,504枚。別店舗の販売価格へ無断置換しない。
- 同一評価時刻の最新URL比較はバリュー17→17、プライオリティ23→23、独立35→35。条件・方式による増加を補完成果にしない。
