# 追加店舗のデータ提供・許諾確認案

未送信の文案。外部送信は利用者の確認後にのみ行う。現在ドラゴンスターは通常HTTP403で停止、カーナベルは自動取得の許諾待ちで、どちらも商品取得未開始。

## 問い合わせ文案

当方はポケモンカードの価格比較・仕入れ検討サイトを運営しています。御社の日本語版カードの商品名、型番、状態別販売価格、在庫有無、商品URLを少量・低頻度で取得し、確認日時・御社へのリンク付きで公開する用途を検討しています。

通常のサイトアクセスではなく、御社が許可するAPI、商品フィード、エクスポート等の正式な提供方法があれば、利用条件と申請方法をご教示ください。自動取得・再公開の可否、対象項目、アクセス頻度、キャッシュ保持期間、商用利用の可否、価格や在庫表示の注意事項を確認したく存じます。

カーナベル様には状態Sと状態Aを別区分で取得できるか、各区分の定義についても確認をお願いしたいです。両区分を同一店舗内の情報として扱い、実在しない購入価格や鑑定結果の保証として表示しません。

許諾をいただくまでは自動収集を開始せず、アクセス制限・認証対策の回避は行いません。

## 再開条件

- 公式窓口からの利用許諾または正式なデータ提供契約・条件を記録する。
- 通常の正規経路で安定アクセスでき、取得頻度・利用範囲を確認する。
- 状態・言語・仕様・単品区分と個別観測日時を保存し、価格/在庫まで小規模検証する。
- 提供方式が確認できなければ停止を維持し、既存の正常店舗巡回は継続する。
