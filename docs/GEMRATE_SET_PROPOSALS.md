# GemRate の確認済みセット提案

PC の受け取り処理が、届いた原票とページの証跡でセット名・年・言語・鑑定会社・行数・POP合計を確かめる。収集専用セットが対象で、初期の S6A は専用経路を使う。

1. 国内カタログの記号・番号・分母・英名・仕様を既存の照合器で照合する。CSVの同一行キー、曖昧な国内候補、同じ国内カードに対する複数仕様は保留する。
2. 対応率の分母は、照合前に決まる通常仕様（Base、Ultra Rare、Art Rare、Special Art Rare、Super Rare、Mega Ultra Rare）の行数。エラー品と明示された行を除く。名前が合わない行や国内カタログにない行も、対象仕様なら分母に含める。過去の保留行を一致枚数に含めない。
3. 各受領で重複0、1対1が20枚以上、対応率50%以上を確認する。設定を移した状態で保存済みの自動受領全件を検証する。初期の手動受領は元の検証記録、原票とバックアップの指紋を照合する。
4. 条件を満たすと、収集設定・確認済み設定・拡張用設定・UI manifest だけをセット別の下書きPRにする。マージは利用者が決める。保留理由は monitor-alert ラベルの監視Issueに追記する。PCの非公開記録に原票と作業結果を残す。

### 拡張で次のセット名を探す案（T4a）

利用者が通常の Chrome で開いている GemRate の PSA 日本語セットページに、該当年のセット選択欄があるかを最初に確かめる。候補の検索は、既に表示された選択肢の文字列だけを使う。年・鑑定会社・カテゴリを照合し、国内カタログの英語商品名に対応する選択肢が1件だけなら、その正式表記と年を候補として示す。同名再録、複数候補、該当なし、一覧の未読込は手動確認とする。

この案はセット名の入力補助まで。受け取ったCSVの行照合と下書きPRの4条件は引き続き必要になる。試作時は保存済みの選択欄で、同名・別年・別仕様の誤採用が0件かを測る。追加通信を要する年一覧の巡回は今回の対象外。
